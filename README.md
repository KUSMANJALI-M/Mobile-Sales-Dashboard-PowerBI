# Mobile Sales Dashboard | Power BI

## Project Overview
This project presents an interactive Mobile Sales Dashboard built using Microsoft Power BI to explore mobile sales performance, monthly quantity trends, customer ratings, payment methods, and brand-wise sales.

## Tools Used
- Microsoft Power BI
- Microsoft Excel (data source)

## Dashboard Features
- **Sales KPIs:** Summary metrics displayed in cards.
- **City-wise Sales Analysis:** Map visualizing total sales by city.
- **Monthly Quantity Analysis:** Line chart showing total quantity by month.
- **Customer Ratings:** Visual breakdown of customer ratings.
- **Payment Method Analysis:** Pie chart showing transactions by payment method.
- **Brand-wise Analysis:** Table comparing total sales, total quantity, and transactions by brand.
- **Mobile Model Analysis:** Bar chart comparing total sales by mobile model.
- **Day-wise Sales Analysis:** Chart comparing total sales by day name.
- **Interactive Filters:** Filters for mobile model, payment method, brand, and day name.

## Project File
- `Mobile Sales Dashboard.pbix` — Power BI dashboard file.

## How to View
Download the `.pbix` file from this repository and open it using Microsoft Power BI Desktop.
